SMART SHRIMP - PROTOTIPO NAVEGABLE

1. Abra index.html en Google Chrome, Microsoft Edge o Firefox.
2. No necesita instalar programas ni tener conexión a Internet.
3. Seleccione uno de los tres perfiles, ingrese sus credenciales y luego accederá al dashboard correspondiente.
4. En el formulario de acceso puede volver a seleccionar otro perfil.
5. Para cualquiera de los tres perfiles use estas credenciales de demostración:
   - Usuario: admin
   - Contraseña: 123

RECORRIDO PRINCIPAL PARA LA TAREA

Ingresar como operador -> Nuevo análisis -> Identificación -> Continuar ->
Analizar imagen o Detección en vivo -> Calibración -> Resultados -> Guardar análisis.

ESTADOS ALTERNATIVOS Y DE ERROR

- En Identificación: pulse "Simular código duplicado".
- En Detección en vivo: pulse "Simular error de cámara".
- En Resultados: pulse "Salir" para abrir la confirmación de salida sin guardar.
- En Historial: pulse "Ver estado vacío".
- En Usuarios: abra "Nuevo usuario" y luego "Simular correo registrado".

ARCHIVOS COMPLEMENTARIOS

- wireframes.html: wireframes previos al diseño final.
- flujo-usuario.html: recorrido principal y ruta alternativa.

IMPORTANTE

Este proyecto es un prototipo visual. No ejecuta Django, YOLO, OpenCV,
almacenamiento real, cámara real ni análisis de inteligencia artificial.
Los datos y resultados se usan únicamente para demostrar la navegación.
